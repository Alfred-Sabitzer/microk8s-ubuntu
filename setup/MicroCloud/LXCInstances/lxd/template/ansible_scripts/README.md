# Scripts

Useful scripts for administrating the horde

| Script Name                         | Description                            | Usage Example                            |
|-------------------------------------|----------------------------------------|------------------------------------------|
| `add_hosts_to_known_hosts.sh`       | Initializes the environment            | `./add_hosts_to_known_hosts.sh`          |
| `all_ping.sh`                       | Ping all the Instances                 | `./all_ping.sh`                          |
| `create_hosts_file.sh`              | updating /etc/hosts                    | `./create_hosts_file.sh`                 |
| `install_crontab.sh`                | initializes crontab for ansible        | `./install_crontab.sh`                   |
| `ssh_copy_id.sh`                    | create authorized_keys on instances    | `./ssh_copy_id.sh`                       |
